# warehouse-operations-sales-analytics-excel
Warehouse Operations &amp; Sales Analytics Model (Excel)


## 📌 Project Overview
This project is an end-to-end Excel-based data model designed to simulate real-world warehouse and logistics operations.

It integrates sales, inventory, deliveries, operational status, and profitability into a single analytical solution.

## 🗂 Data Model Structure

### 1️⃣ Database
- Product
- Warehouse location
- Storage zone
- Delivery destination
- Operational status
- Unit of measure

### 2️⃣ Operations Tracking
- Delivery date
- Storage location (bin system)
- Quantity
- Unit purchase price
- Transport cost
- Operational status:
  - Delivered
  - Returned
  - Pending

### 3️⃣ Sales & Profitability Analysis
- Quantity received
- Quantity sold
- Remaining stock
- Revenue
- Total cost
- Profit calculation

### 4️⃣ HR Cost Simulation
- Salary calculation
- Overtime payment
- Weekend payment

### 5️⃣ Max / Min Analysis
- Identification of best and worst performing products

## ⚙️ Tools & Techniques
- Microsoft Excel
- Structured Tables
- Data Validation (drop-down lists)
- Conditional Formatting
- IF logic
- Profit calculations
- Data aggregation
- Basic dashboard visualization

## 📊 Key Business Insights
The model helps to:
- Track warehouse stock by location
- Monitor delivery performance
- Identify returned and pending orders
- Calculate product-level profitability
- Analyze top and low performing items
- Simulate operational workforce costs

## 🧠 Business Value
This solution replicates a real logistics workflow and supports:
- Operational decision-making
- Inventory control
- Profitability analysis
- Warehouse performance tracking
